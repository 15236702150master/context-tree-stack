# Security

Please do not include API keys, database passwords, local rollout files,
`credentials.json`, `.env` files, or personal screenshots in issues or pull
requests.

For a suspected vulnerability, use a private GitHub Security Advisory for the
repository rather than posting exploit details publicly. Include the affected
file/version, a minimal reproduction, and the impact. The sidecar should remain
bound to loopback unless it is protected by an HTTPS reverse proxy.
